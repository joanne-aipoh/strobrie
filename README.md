# Strobriē By Joanne

The main website for **Strobriē By Joanne**, a cafe and bakery in Abuja,
Nigeria. Content and branding are based on [@strobrie on Instagram](https://instagram.com/strobrie).

## Running locally

This is a static site — no build step required. Open `index.html` directly in
your browser, or serve the folder locally:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Structure

- `index.html` — page markup and content
- `styles.css` — styling
- `script.js` — small bits of interactivity
