# Strobrie

The main website for **Strobrie**, a cafe by Joanne in Abuja, Nigeria.

## Running locally

This is a static site — no build step required. Open `index.html` directly in
your browser, or serve the folder locally:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Structure

- `index.html` — page markup and content
- `styles.css` — styling
- `script.js` — small bits of interactivity
